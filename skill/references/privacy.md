# 隐私声明

本 Skill 完全在本地运行，不发起任何网络请求，不连接任何服务器，
不上传、不共享、不收集用户数据。

1. **读取范围**：仅读取用户在对话中粘贴的内容，或用户明确指定的本地文件/目录。
   不读取未指定路径；不扫描系统目录、浏览器配置、密码库、SSH 密钥、系统凭据。
2. **敏感文件**：.env / *.pem / id_rsa / credentials / cookies / *.sqlite 等敏感文件
   只报告文件名（存在性），不读取、不展示其内容。
3. **写入范围**：默认不写入任何文件。仅在命中较多（>10 条）或用户明确要求时，
   将**脱敏后**的报告写入用户指定目录或系统临时目录；不修改被扫描文件。
4. **网络与第三方**：无任何网络调用，无第三方 SDK，无遥测/统计，无版本检查或规则下载。
5. **数据处理**：检测在内存中完成，进程结束即释放；报告中只保存脱敏证据
   （类型 + 长度 + 哈希前缀 + ≤40 字符片段），不保存原文。
6. **权限**：仅需读取本地文件的能力（storage）。
7. **用户控制**：用户可随时终止扫描、限定范围；检测结果仅供参考，
   本 skill 不自动处置任何文件。
8. **联系**：https://github.com/a9320/tianxi-ai-content-guard
