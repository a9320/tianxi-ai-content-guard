# 防御性用途说明（Defensive Purpose Statement）

本 skill 是**防御性安全检测工具**，供用户对自己收到的内容、自己的文件与仓库做安全审计。

## 检测特征字符串的性质

引擎包含提示注入指令、越狱短语、零宽字符、编码载荷等**攻击特征样本**——它们是
检测规则本身（只读字符串匹配），不是可执行的攻击代码。零宽字符等不可见字符在
规则与输出中一律以 `U+XXXX` 记法呈现，不以原字符存储或输出。

## 代码边界（可用 --self-check 现场验证）

- 不执行被扫描内容中的任何代码、命令、URL；
- 无 Python 动态执行（无 eval / exec / os.system / subprocess / pickle.loads；compile 仅指 re.compile 正则预编译）；
- 无网络模块导入，不发起任何请求，不上传任何数据；
- 默认不写文件（仅命中较多或用户 --out 时写脱敏报告）；
- base64 解码仅用于"还原后匹配"（`--decode` 复核 ≤3 层；引擎剥离链最多 5 层；输入 ≤64KB / 输出 ≤256KB），
  解码结果只做字符串匹配与脱敏展示，不落盘不执行；
- 引擎文件带 SHA-256 锚（scripts/engine/ENGINE-ANCHOR.txt），可核验完整性。

## 规则来源

检测规则基于 Arcanum Prompt Injection Taxonomy v1.6.1
（Jason Haddix, Arcanum Information Security, CC BY 4.0）派生，编号与官方对齐，
不编造编号 / CWE / CVE。MITRE ATLAS 映射 AML.T0051.001。

## 检测结果的使用限制

输出仅用于提示用户内容风险，不自动删除、隔离或修改任何文件；
"未检出"不代表内容安全（详见 SKILL.md §5）。

## 已知边界（2026-11-04 第三方实测确认，v1.2.16）

以下两类**会报 high，但属正当内容**——确定性层不区分"描述攻击"与"发出指令"，
这是模式匹配的原理性限制，只能人工豁免，不能靠调参消除：

| 场景 | 实测判决 | 处置建议 |
|---|---|---|
| 正当 RTL 文案中的隔离符（U+202A–202E 等） | malicious（PIT-E-54 high ×1） | 确认语境后人工豁免 |
| 安全教材 / 研究文档原文引用攻击句式 | malicious（PIT-N-06 high ×1） | 逐条人审，不当作真实指令 |

与之相对，emoji 家族序列内的 ZWJ、UTF-16 BOM 两类边界引擎已内置处理
（前者自动降级 low，后者解码链识别，均判 clean），无需人工介入。

**会漏检的方向（覆盖不到）**

- 语义改写类攻击：拆句、隐喻、图片/表格承载等不含特征措辞的劫持；
- 凭据泄露本身：引擎只找攻击模式，不识别凭据内容；命名不在敏感名单内的
  凭据文件（如 `secret.env`）会被当普通文本读取，判 clean 不代表其中没有验证信息。

**参数语义提醒（易误解）**

- `--min-severity` 只过滤 `top_findings` 的展示条数，**不改 `counts`、不改 `verdict`**；
  不能当"降级判决"用。
- `--fail-on high` 时，仅 medium 命中的内容（如单层编码）不会让 CI 失败；
  CI 门槛需按团队策略显式选定。
